    Each package is a section, and each box in it is an area, a folder of modules. Columns are layers, the lowest on the left: an area imports only from columns to its left, unless it is marked cycle, which means it and other areas in its column depend on each other. Select a box to list its modules in the panel, where ← 3 counts the code that imports a module and → 5 the modules it imports. Select a box, or the circle at the end of a module's row, to mark its dependencies and its dependents. The address keeps the selection, so a link opens the same view.
